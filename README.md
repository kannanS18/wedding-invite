# 💍 Sri Krishna & Swetha — Royal Wedding Invitation

A production-grade, immersive wedding invitation web experience for **Sri Krishna & Swetha's Wedding**, celebrating on **Sunday, 25 October 2026** at **Meeting Hall Konnakulam, Manamadurai**.

🌐 **Live Website**: [https://kannans18.github.io/wedding-invite/](https://kannans18.github.io/wedding-invite/)

---

## ✨ Key Highlights

1. **Traditional Preloader (Thamboolam Plate Artwork)**:
   - Handcrafted auspicious SVG plate with betel leaves (vetrilai), areca nut (paakku), brass diya flame, jasmine garland, and golden invitation card.
   - Smooth binary RAM preloading for seamless intro video playback.

2. **Cinematic Intro Video Experience**:
   - Streamed instantly from device memory with zero stutter.
   - Elegant interactive "Scroll Down" invitation reveal.

3. **Royal Invitation & Auspicious Muhurtham**:
   - High-fidelity typography featuring *Great Vibes*, *Playfair Display*, and *Montserrat*.
   - Subha Muhurtham: **10:30 AM – 11:30 AM**.

4. **Photorealistic 3D Mechanical Flip Clock**:
   - Dynamic 3D date cascade built with React Three Fiber (`@react-three/fiber`), Drei, and Three.js.
   - Real-time device gyroscope tilt & parallax.
   - "Add to Calendar" and Google Maps navigation integration.

5. **Auspicious Ceremonial Photo Gallery**:
   - 8 curated high-resolution couple portraits with responsive WebP formatting.
   - Fullscreen lightbox viewer with keyboard navigation and touch gestures.

6. **Venue & Transportation Navigation**:
   - Interactive Google Maps location preview with QR code for mobile scanning.
   - Nearby transit landmarks (Madurai Junction, Madurai Airport, Manamadurai).

7. **Celebratory Background Music**:
   - Melodious ceremonial soundtrack ("Dumm Dumm" - Darbar) at balanced 70% volume.
   - Dedicated floating audio toggle with playback persistence across navigation.

8. **Rich Social Link Sharing (WhatsApp / Facebook / Twitter)**:
   - Customized OpenGraph and Twitter Cards previewing `wedding_share_preview.jpg` (1200x630).

## 🛠️ Local Development

### Prerequisites
- Node.js `v18+` or `v20+`
- npm

### Run Locally
```bash
npm install
npm run dev
```

### Build for Production
```bash
npm run build
npm run preview
```
